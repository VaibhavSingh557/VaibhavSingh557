## 🧠 My Abilities & Core Competencies

Rather than just writing code, I focus on understanding the entire technology stack from the operating system level up to the web browser. 

> **🛡️ Cybersecurity & Forensics**
> Deep understanding of active network defense, threat modeling, and vulnerability assessment. I build tools for network reconnaissance, memory forensics, and Zero-Trust architecture simulations to stay ahead of modern threats.

> **🐍 Advanced Python Development**
> Python is my primary weapon. I specialize in writing complex backend logic, multi-threaded applications, and automated scripts. Whether it's building RESTful APIs, parsing ASTs, or creating cryptographic simulators, I push Python to its limits.

> **💻 Operating System Mastery (Linux & Windows)**
> I am highly proficient in navigating, managing, and securing both **Linux** (Ubuntu, Kali, Debian) and **Windows** environments. I understand cross-platform execution, system administration, bash/batch scripting, and kernel-level behavior.

> **🌐 Full-Stack Web Development**
> I bring heavy backend algorithms to life using modern web technologies. I build responsive, zero-refresh, interactive frontend architectures (HTML, CSS, JavaScript, React) connected to hardened backend servers (Flask, Node) to create seamless user experiences.
